# Загальні правила проєкту

## Мова та стиль
- Коментарі у коді — англійська
- Документація (docs/) — українська
- Назви файлів: `snake_case`
- Назви класів: `PascalCase`
- Константи: `UPPER_SNAKE_CASE`

## Python
- Версія: 3.10+
- Обов'язкові type hints для публічних функцій
- Обов'язковий docstring для класів та публічних методів
- Виключення: завжди логувати перед raise
- Не використовувати `print()` у продакшн-коді — тільки `logging`

## Структура файлів
- Один клас/модель — один файл
- Максимальний розмір файлу: 300 рядків (якщо більше — розбити)
- Кожна папка має містити `__init__.py` (для Python-пакетів)

## Залежності
- Всі зовнішні залежності фіксувати у `requirements.txt`
- Версії пінити точно: `requests==2.31.0`

## Безпека
- Паролі та токени — тільки через змінні середовища або `.env` файл
- `.env` завжди у `.gitignore`
- Не логувати паролі, токени, персональні дані
