# Skill: Міграція даних між інстансами Odoo через RPC

## Команда
> "Створи скрипт міграції для [модель] з [source] в [target]"

## Вхідні дані
- `model` — назва ORM-моделі (наприклад `res.partner`)
- `fields` — список полів для копіювання
- `source_url` / `source_db` — джерело
- `target_url` / `target_db` — ціль
- `unique_field` — поле для перевірки дублів (наприклад `email`)

## Кроки виконання
1. Підключитись до source через XML-RPC та автентифікуватись
2. Підключитись до target через XML-RPC та автентифікуватись
3. Отримати записи з source через `search_read` батчами по 100
4. Для кожного запису: перевірити дубль у target за `unique_field`
5. Якщо дубль — пропустити або оновити (залежно від параметра `mode`)
6. Якщо немає — створити через `create`
7. Логувати результат: created / skipped / errors
8. Зберегти log у `scripts/logs/<model>_migration_<date>.log`

## Режими
- `mode=create_only` — пропускати існуючі (default)
- `mode=update_existing` — оновлювати існуючі
- `mode=full_sync` — синхронізація в обидва боки

## Увага: Many2one поля
ID записів відрізняються між базами.
Потрібен окремий маппінг: спочатку мігрувати залежні моделі,
потім основну з підстановкою нових ID.
