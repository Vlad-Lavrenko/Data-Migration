# Data-Migration

Одoo 18.0 — утиліти для міграції та синхронізації даних між інстансами Odoo через RPC (XML-RPC / JSON-RPC).

## Можливості

- Копіювання контактів (`res.partner`) між базами
- Синхронізація будь-яких ORM-моделей через External API
- Завантаження модулів з remote-сервера

## Вимоги

- Python 3.8+
- Odoo 18.0
