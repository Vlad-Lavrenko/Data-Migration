# Вимоги до проєкту Data-Migration

> Цей файл оновлюється по мірі розробки.

## Функціональні вимоги

### FR-01: Міграція контактів
- Копіювати `res.partner` між двома Odoo 18.0 інстансами через XML-RPC
- Перевірка дублів за полем `email`
- Режими: `create_only`, `update_existing`

### FR-02: Міграція довільних моделей
- Параметризований скрипт: передати назву моделі та список полів
- Батчинг по 100 записів

### FR-03: Завантаження модуля з remote сервера
- Кастомний HTTP-контролер на Odoo для віддачі ZIP
- Клієнтський скрипт для завантаження та розпакування

## Нефункціональні вимоги

- NFR-01: Логування всіх операцій у файл
- NFR-02: Не зберігати паролі у коді — тільки `.env`
- NFR-03: Підтримка Odoo 18.0
- NFR-04: Python 3.10+
